# 教练与电脑对手

即时分析使用 [thlorenz/phe](https://github.com/thlorenz/phe) 的快速牌力评估，许可为 [MIT](https://github.com/thlorenz/phe/blob/master/LICENSE)。游戏规则和权益抽样在本项目中实现，运行时不调用云端模型，也不需要 API 密钥。

## 电脑如何决策

每个电脑只接收 `room.snapshot(自己的玩家 ID)`。未知底牌不会作为输入；即使调用者提供了其他玩家的明牌，分析也不把它们当作已知手牌。电脑根据座位、公开行动、当前公共牌和风格假设对手可能持有的范围，再抽样剩余牌，比较最佳五张牌。平分底池按实际份额计入权益。

建议结合位置、翻前手牌、筹码深度、权益、跟注成本以及价值下注和听牌机会。电脑使用合法操作和可行的加注金额，平衡、紧手、激进风格改变范围和行动倾向。它比原先仅根据最高底牌和随机数行动的练习对手更能考虑局面，但没有加载职业级预训练策略。

## 如何看提示

- **权益**：对假设对手范围和随机剩余牌的摊牌份额估算，不是这一手最后获胜的确定概率。
- **跟注门槛**：跟注成本与跟注后可竞争底池的比例。单纯比较权益与门槛忽略后续下注、弃牌权益及权益实现率，需要结合文字解释。
- **推荐操作**：当前模型的参考选择。加注数字表示本轮累计下注总额。
- **决策反馈**：衡量自己的选择与参考建议是否一致；并非精确 EV 损失、胜率排名或职业水平评分。
- **抽样与范围**：样本增加可以减少抽样误差，但不能消除对手范围猜错造成的偏差。

Solver 是独立分析来源。它对明确的双方范围、有效筹码和下注树求解策略频率；这些输入与现实对手不一致时，结果也会变化。当前支持范围和设置见 [SOLVER.md](SOLVER.md)。

## 研究过的其他项目

[RLCard](https://github.com/datamllab/rlcard) 是牌类强化学习研究环境，包含不同游戏与训练示例。它的示例和抽象行动空间不能直接当成本游戏 2–9 人任意加注规则下的成熟策略，因此没有冒充已接入的强模型。[postflop-solver](https://github.com/b-inary/postflop-solver) 提供 Rust 翻后求解库；当前先采用 TexasSolver 的命令行和 JSON 结果接口。
